# Iteration 4 型システムと型安全性

Iteration 4で扱う意味論の考え方を説明する．
例には，自然数と真偽値を持つ小さな言語の式を使う．

## 型付け規則

型は，式を評価したときにどの種類の値になるかを，評価する前に予測するものである．
型付け規則は，「部分式の型がこうなら，式全体の型はこうなる」という推論規則として書く．

```math
\frac{t_1 : \mathsf{Nat} \quad t_2 : \mathsf{Nat}}{t_1 + t_2 : \mathsf{Nat}}
\qquad
\frac{c : \mathsf{Bool} \quad t : T \quad e : T}{\mathsf{if}\ c\ \mathsf{then}\ t\ \mathsf{else}\ e : T}
```

型付け規則は，評価の規則と違って式を書き換えない．
式の形だけを見て，部分式から順に型を決める．
このような意味を，評価の意味(動的意味論)に対して，静的意味論という．

## 型システムは安全側の近似である

$\mathsf{if}\ \mathsf{true}\ \mathsf{then}\ 0\ \mathsf{else}\ \mathsf{false}$を評価すると$0$になり，行き詰まらない．
しかし`if`の規則は2つの枝が同じ型を持つことを求めるので，この式には型が付かない．

型検査は評価する前に行うので，どちらの枝が選ばれるかを知らずに判断する．
そのため，「行き詰まらない式」の一部を，安全のために拒否する．
型システムを設計するときは，拒否する式を減らすことと，規則を単純に保つことの間で選択する．

## 型安全性

型システムの目標は，型の付く式が行き詰まらないことを保証することである．
これを型安全性という．

```math
t : T \land t \longrightarrow^{*} t' \implies \neg \mathit{Stuck}(t')
```

型安全性は，2つの補題に分けて証明するのが定石である．

- 進行(progress)：型の付く式は，値であるか，1ステップ簡約できる．
- 保存(preservation)：型の付く式を1ステップ簡約しても，型は変わらない．

保存によって，簡約列のどの式にも型が付く．
進行によって，型の付く式は行き詰まっていない．
2つを合わせると，簡約列のどの式も行き詰まらない．

## 標準形補題

進行の証明では，部分式が値のとき，その値の形を知る必要がある．
足し算$v_1 + v_2$を計算するには，$v_1$と$v_2$が数でなければならない．

型から値の形がわかる，という補題を標準形補題という．

- 型$\mathsf{Nat}$を持つ値は，数である．
- 型$\mathsf{Bool}$を持つ値は，$\mathsf{true}$か$\mathsf{false}$である．

## 型検査器の健全性と完全性

型付け規則は仕様であり，型検査器は実装である．
評価器と同じく，2つが一致することを確かめる．

- 健全性：型検査器が返す型は，型付け規則でも式の型である．
- 完全性：型付け規則で式の型が$T$なら，型検査器も$T$を返す．

健全性があれば，型検査を通った式について，型安全性の定理を使える．
完全性があれば，型付け規則で型の付く式を，型検査器が誤って拒否することはない．

## 型の一意性

この言語では，1つの式の型はたかだか1つに決まる．
型検査器の完全性から，2つの型がどちらも型検査器の結果に等しいことを示せば証明できる．
`if`の規則が両方の枝に同じ型を求めていることが，型の一意性を支えている．

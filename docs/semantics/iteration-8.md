# Iteration 8 推論規則を設計する

Iteration 8では，組の推論規則を自分で設計する．
このノートでは，規則を設計するときに決めることと，その決定が性質に与える影響を説明する．
例には，自然数と組を持つ小さな言語の式を使う．

## 組と射影

組$(t, u)$は，2つの式をまとめた式である．
射影$\mathsf{fst}\ t$と$\mathsf{snd}\ t$は，組の1つ目と2つ目の成分を取り出す．
組の型は$A \times B$と書く．

```math
\mathsf{fst}\ (1 + 2, \mathsf{true}) \Downarrow 3
```

構文と型はすぐに決まるが，評価の規則にはいくつかの選び方がある．

## 決めること

### 組はいつ値になるか

1つ目の選び方は，成分を値まで評価してから組を値とする設計である(先行評価)．

```math
\frac{\mathit{value}(t) \quad \mathit{value}(u)}{\mathit{value}((t, u))}
```

2つ目の選び方は，成分を評価しないまま組を値とする設計である(遅延評価)．

```math
\frac{}{\mathit{value}((t, u))}
```

遅延評価では，射影するときに初めて成分を評価する．
$\mathsf{fst}\ (1, \mathit{loop}\ 0)$は，遅延評価なら$1$になり，先行評価なら評価が終わらない．
Iteration 6の値呼びと名前呼びの違いと同じ構図である．

### 成分をどの順に評価するか

先行評価を選んだら，成分を簡約する順序も決める．
左の成分から簡約するなら，右の成分を簡約する規則の前提に「左の成分が値である」ことを置く．

```math
\frac{t \longrightarrow t'}{(t, u) \longrightarrow (t', u)}
\qquad
\frac{\mathit{value}(v) \quad u \longrightarrow u'}{(v, u) \longrightarrow (v, u')}
```

この前提を落とすと，$(1 + 2, 3 + 4)$は2通りに簡約できてしまう．
Iteration 3の`then`の枝を先に簡約する規則と同じく，規則の左辺が重なって決定性が成り立たなくなる．
Miniには副作用がないので，どちらの順序でも最後の値は同じである．
副作用のある言語では，評価の順序はプログラムの結果を変える．

### 射影はいつ成分を取り出すか

先行評価では，組が値になってから成分を取り出す．

```math
\frac{\mathit{value}(v) \quad \mathit{value}(w)}{\mathsf{fst}\ (v, w) \longrightarrow v}
```

この規則では，使わない成分$w$も評価してから捨てる．

## 設計が性質に与える影響

規則を足したら，これまでの性質が保たれるかを確かめる．

- 決定性：同じ式に当てはまる規則が2つ以上あると崩れる．各構文で，どの部分式を先に簡約するかを1つに決める．
- 進行：型の付く閉じた式が，値であるか1ステップ簡約できることを示す．組の型を持つ値は組であるという標準形補題が要る．
- 保存：射影の規則で，取り出した成分の型が射影の型と一致することを示す．
- 2つの意味論の一致：大ステップ意味論の規則と小ステップ意味論の規則が，同じ値を与えるように設計する．

先行評価を選ぶと，値を表す式の成分もまた値を表す式になる．
そのため，置換に使う式は閉じた値を表す式に限られたままで，置換補題をそのまま使える．
一方で，値の定義が再帰的になるので，値についての補題の証明は帰納法になる．

## まとめ

このハンズオンでは，Miniの構文を1つ足すたびに，次の手順を繰り返してきた．

1. 構文と値を決める．
2. 大ステップ意味論と小ステップ意味論の規則を設計する．
3. 型付け規則を設計する．
4. 決定性，2つの意味論の一致，評価器の正しさ，型安全性が保たれることを証明する．

規則の小さな違いが，どの性質が成り立つかを決める．
性質を定理として書き，証明が通るかで設計を確かめることが，操作的意味論による言語設計である．

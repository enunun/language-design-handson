# Iteration 5 変数と置換

Iteration 5で扱う意味論の考え方を説明する．
例には，真偽値と`let`を持つ小さな言語の式を使う．

## 束縛と自由な変数

$\mathsf{let}\ x = t\ \mathsf{in}\ u$は，$u$の中で$x$を$t$の値として使えるようにする．
このとき，$\mathsf{let}$は$u$の中の$x$を束縛するという．

式の中の変数のうち，それを束縛する$\mathsf{let}$の中にないものを，自由な変数という．

- $\mathsf{let}\ x = \mathsf{true}\ \mathsf{in}\ x$では，$x$は束縛されている．
- $\mathsf{let}\ x = \mathsf{true}\ \mathsf{in}\ y$では，$y$は自由である．
- 自由な変数を持たない式を，閉じた式という．プログラムは閉じた式である．

同じ名前の束縛が入れ子になると，内側の束縛が外側の束縛を隠す．
$\mathsf{let}\ x = \mathsf{true}\ \mathsf{in}\ \mathsf{let}\ x = \mathsf{false}\ \mathsf{in}\ x$の値は$\mathrm{false}$である．

## 置換

$t[x := v]$は，$t$の中の自由な$x$を，すべて$v$で置き換えた式である．
束縛された$x$は置き換えない．

```math
(\mathsf{let}\ x = b\ \mathsf{in}\ x)[x := \mathsf{true}] = \mathsf{let}\ x = b[x := \mathsf{true}]\ \mathsf{in}\ x
```

本体の$x$は，内側の$\mathsf{let}$に束縛されているので置き換えない．
束縛する式$b$の中の$x$は，外側の$x$なので置き換える．

## 変数の捕獲

置換する式$v$が自由な変数を持つと，困ったことが起きる．
$(\mathsf{let}\ y = \mathsf{true}\ \mathsf{in}\ x)[x := y]$を素朴に計算すると，$\mathsf{let}\ y = \mathsf{true}\ \mathsf{in}\ y$になる．
外側の$y$を指していたはずの変数が，内側の$\mathsf{let}$に束縛されてしまった．
これを変数の捕獲という．

捕獲を避ける方法はいくつかある．

- 置換の途中で，束縛する変数の名前を，ぶつからない名前に付け替える．
- 変数を名前ではなく，束縛までの距離(de Bruijnインデックス)で表す．
- 置換する式を，自由な変数を持たない閉じた式に限る．

Miniでは3つ目の方法をとる．
評価では，値(閉じた式)だけを置換するからである．

## 値呼びの`let`

Miniの$\mathsf{let}\ x = t\ \mathsf{in}\ u$は，まず$t$を値$v$まで評価し，それから$u[x := v]$を評価する．
このような評価の順序を値呼びという．

```math
\frac{t \Downarrow v \quad u[x := v] \Downarrow w}{\mathsf{let}\ x = t\ \mathsf{in}\ u \Downarrow w}
```

値呼びでは，$x$を使わない本体でも$t$を評価する．
$t$を評価せずに式のまま置き換える方法(名前呼び)もある．
Iteration 6で，関数の引数について2つを比べる．

## 型付け文脈

変数の型は，その変数を束縛した$\mathsf{let}$で決まる．
型付け規則は，束縛された変数とその型の列(型付け文脈$\Gamma$)を持ち回る．

```math
\frac{\Gamma(x) = T}{\Gamma \vdash x : T}
\qquad
\frac{\Gamma \vdash t : T \quad (x : T), \Gamma \vdash u : U}{\Gamma \vdash \mathsf{let}\ x = t\ \mathsf{in}\ u : U}
```

プログラムは空の文脈で型を検査する．
自由な変数を持つ式には，空の文脈では型が付かない．

## 置換補題

$\mathsf{let}$の簡約では，本体の変数を値で置き換える．
保存(簡約しても型が変わらない)を示すには，置換が型を保つことが要る．

```math
(x : A), \Gamma \vdash u : B \ \land\ \vdash v : A \implies \Gamma \vdash u[x := v] : B
```

これを置換補題という．
証明は$u$についての帰納法で行う．
$\mathsf{let}$の場合は，文脈の並びが変わるので，次の補題を使う．

- 弱化：文脈を広げても，型付けは保たれる．
- 隠された束縛：$(x : T), (x : A), \Gamma$での型付けは，$(x : T), \Gamma$での型付けと同じである．
- 交換：名前の異なる2つの変数は，文脈の中で順序を入れ替えてよい．

## 燃料つきの評価器

$\mathsf{let}$の本体に値を置換した式は，元の式の部分式ではない．
そのため，評価器を式の構造についての再帰では定義できない．
Miniの評価器は，1ステップの簡約を燃料の回数まで繰り返す．

燃料つきの評価器の正しさは，次の2つで述べる．

- 健全性：評価器が値を返したら，それは大ステップ意味論での式の値である．
- 完全性：大ステップ意味論で式に値があれば，燃料が十分なら評価器はその値を返す．

型安全性と組み合わせると，型の付くプログラムの評価は，値に着くか燃料を使い切るかのどちらかで，行き詰まることはない．

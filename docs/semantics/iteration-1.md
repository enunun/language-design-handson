# Iteration 1 推論規則と大ステップ意味論

Iteration 1で扱う意味論の考え方を説明する．
例には，Iteration 0のノートと同じ，真偽値の式からなる小さな言語を使う．

## 推論規則

推論規則は，「前提がすべて成り立つならば，結論が成り立つ」という形の規則である．
横線の上に前提を，下に結論を書き，右に規則の名前を書く．

```math
\frac{b \Downarrow v}{\mathsf{not}\ b \Downarrow \neg v}\ \textsf{not}
```

この規則は，「式$b$が$v$に評価されるならば，$\mathsf{not}\ b$は$\neg v$に評価される」と読む．
前提のない規則は，横線の上を空にする．

```math
\frac{}{\mathsf{true} \Downarrow \mathrm{true}}\ \textsf{true}
\qquad
\frac{}{\mathsf{false} \Downarrow \mathrm{false}}\ \textsf{false}
```

規則の中の$b$や$v$は，任意の式や値を表す変数である．
1つの規則は，変数に何を入れても成り立つ無数の主張をまとめて表している．

## 導出木

規則を組み合わせると，ある主張が成り立つ理由を木の形で示せる．
この木を導出木という．
次は$\mathsf{not}\ (\mathsf{not}\ \mathsf{true}) \Downarrow \mathrm{true}$の導出木である．

```math
\dfrac{\dfrac{\dfrac{}{\mathsf{true} \Downarrow \mathrm{true}}\ \textsf{true}}
             {\mathsf{not}\ \mathsf{true} \Downarrow \mathrm{false}}\ \textsf{not}}
      {\mathsf{not}\ (\mathsf{not}\ \mathsf{true}) \Downarrow \mathrm{true}}\ \textsf{not}
```

推論規則で定めた関係は，「導出木を作れる主張の全体」である．
導出木を作れない主張は成り立たない．

## 大ステップ意味論

$b \Downarrow v$のように，式とその最終的な値の関係を推論規則で定める方法を，大ステップ意味論(自然意味論)という．
評価の途中経過は書かず，部分式の値から式全体の値を決める規則を並べる．

Iteration 0では，評価器の等式で意味を定めた．
大ステップ意味論は，関数ではなく関係として意味を定める．
関係で定めると，次のような意味も自然に書ける．

- 値を1つに決められない言語(たとえば，乱数を返す式を持つ言語)．
- 評価の終わらない式を持つ言語．その式は，どの値とも関係を持たない．

Leanでは，大ステップ意味論は帰納的述語として定義する．
規則の1つ1つが構成子に，導出木が構成子を組み合わせた証明に対応する．

## 仕様と実装

大ステップ意味論は「式の値とは何か」を定める仕様である．
評価器は，その値を計算する実装である．
2つを別々に定義したら，実装が仕様に従うことを確かめる．

- 健全性：評価器が返す値は，仕様のうえでも式の値である．
- 完全性：仕様のうえで式の値であるものを，評価器は返す．

健全性と完全性がそろえば，評価器と仕様は同じ意味を与えている．

## 決定性

どの式についても値がたかだか1つに決まるとき，意味論は決定的であるという．

```math
b \Downarrow v \land b \Downarrow v' \implies v = v'
```

関係で定めた意味論では，決定性は自動的には成り立たない．
規則の組み合わせ方によっては，同じ式に2つの導出木ができ，値が2つになることがある．
決定性は，証明すべき性質である．

評価器の完全性が示せれば，決定性はすぐに従う．
$b \Downarrow v$と$b \Downarrow v'$が成り立つとする．
完全性によって$\mathit{eval}(b) = v$と$\mathit{eval}(b) = v'$が得られるので，$v = v'$となる．
関数は同じ引数に対して1つの値しか返さないからである．

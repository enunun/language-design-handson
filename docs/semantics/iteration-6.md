# Iteration 6 関数と単純型付きラムダ計算

Iteration 6で扱う意味論の考え方を説明する．
例には，真偽値と関数を持つ小さな言語の式を使う．

## 関数を値として扱う

$\mathsf{fun}\ (x : A) \Rightarrow t$は，引数$x$を受け取り$t$を計算する関数である．
関数は，それ以上評価しない値として扱う．
関数の本体$t$は，関数が適用されるまで評価しない．

関数は値なので，変数に束縛したり，別の関数の引数や結果にしたりできる．
関数を引数や結果に使う関数を，高階関数という．

```math
(\mathsf{fun}\ (f : \mathsf{Bool} \rightarrow \mathsf{Bool}) \Rightarrow f\ (f\ \mathsf{true}))\ (\mathsf{fun}\ (b : \mathsf{Bool}) \Rightarrow \mathsf{not}\ b)
```

この式の値は$\mathrm{true}$である．

## β簡約

関数適用の計算は，関数の本体の引数を，実際の引数で置き換えることである．

```math
(\mathsf{fun}\ (x : A) \Rightarrow b)\ v \longrightarrow b[x := v]
```

この規則をβ簡約という．
関数と関数適用と変数だけからなる計算体系を，ラムダ計算という．
ラムダ計算は，関数型言語の意味論の基礎である．

## 値呼びと名前呼び

β簡約の前に引数を評価するかどうかで，評価戦略が分かれる．

- 値呼び：引数を値まで評価してから，本体に置換する．Miniはこの戦略をとる．
- 名前呼び：引数を評価せず，式のまま本体へ置換する．引数は，本体で値が必要になってから評価する．

```math
(\mathsf{fun}\ (x : \mathsf{Bool}) \Rightarrow \mathsf{true})\ t
```

$x$を使わない関数に，評価に時間のかかる式$t$を渡したとする．
値呼びでは$t$を評価してから$\mathsf{true}$になる．
名前呼びでは，$t$を評価しないまま値$\mathsf{true}$を得る．

値呼びでは，置換する式がいつも値なので，閉じた値だけを置換すればよい．
名前呼びでは，自由な変数を持つ式を置換することがあるので，変数の捕獲を避ける工夫が要る．
Iteration 7で，評価が終わらない式を引数にすると，2つの戦略の違いが結果に現れる．

## 単純型付きラムダ計算

関数に型を付けると，関数型$A \rightarrow B$が現れる．

```math
\frac{(x : A), \Gamma \vdash t : B}{\Gamma \vdash \mathsf{fun}\ (x : A) \Rightarrow t : A \rightarrow B}
\qquad
\frac{\Gamma \vdash t_1 : A \rightarrow B \quad \Gamma \vdash t_2 : A}{\Gamma \vdash t_1\ t_2 : B}
```

関数の引数には型の注釈$(x : A)$を書く．
注釈があるので，型検査器は本体の型を求めるときに$x$の型を知っている．

この型システムを持つラムダ計算を，単純型付きラムダ計算という．
単純型付きラムダ計算でも，進行と保存が成り立ち，型安全性が証明できる．

- 進行の証明では，関数型の標準形補題を使う．関数型を持つ値は関数なので，引数が値ならβ簡約できる．
- 保存の証明では，β簡約の場合に置換補題を使う．Iteration 5で`let`のために示した置換補題が，そのまま使える．

## 正規化

単純型付きラムダ計算では，型の付く式の評価は必ず終わる．
この性質を正規化という．
正規化の証明には，式の大きさについての帰納法では足りない．
関数を置換するβ簡約では，簡約した後の式のほうが大きくなりうるからである．
正規化は，型に沿って定義する述語(論理関係)を使って証明する．
このハンズオンでは扱わない．

Iteration 7で再帰関数を足すと，正規化は成り立たなくなる．
型安全性は成り立ち続ける．

# Iteration 6 関数と関数適用

このIterationでは，Miniに関数`fun (x : T) => t`と関数適用`t u`，関数型`T → U`を足す．
引数は値まで評価してから関数に渡す(値呼び)．
Miniは単純型付きラムダ計算になり，その型安全性を証明する．

## 6-1 準備

このパッケージは，Iteration 5の解答と同じ状態から始まる．

``` sh
cd iterations/iteration-6/exercise

```

Iteration 5までのテストがすべて通ることを確かめる．

## 6-3 テストリスト

### 要件

- 関数`fun (x : T) => t`と関数適用`t u`，関数型`T → U`を足す．
- 引数は値まで評価してから関数に渡す(値呼び)．

### 使用例

```text
$ lake exe mini eval "let double = fun (x : Nat) => x + x in double 21"
42
$ lake exe mini check "fun (x : Nat) => iszero x"
Nat → Bool
$ lake exe mini steps "(fun (x : Nat) => x + 1) 2"
(fun (x : Nat) => x + 1) 2
⟶ 2 + 1
⟶ 3
```

### 作るもの

| モジュール | 定義 | 内容 |
| --- | --- | --- |
| `Mini.Syntax` | `Ty`の構成子`arrow (A B : Ty)` | 関数型 |
| | `Term`の構成子`lam (x : String) (A : Ty) (t : Term)`，`app (t u : Term)` | 関数と関数適用 |
| | `Value`の構成子`lam (x : String) (A : Ty) (t : Term)` | 関数の値 |
| `Mini.SmallStep` | `IsValue`の構成子`lam` | 関数は値を表す式である |
| `Mini.Typing` | `TypeError`の構成子`notFunction (actual : Ty)` | 関数でない式の適用 |
| そのほか | 各モジュールに関数と関数適用の場合を足す | |

型エラーの表示は，引数の型が合わないときは`関数の引数の型が合わない(期待：Nat，実際：Bool)`の形に，関数でない式を適用したときは`関数でない式を適用している(型：Nat)`の形にする．
関数の値は，その関数を表す式として表示する．
関数型の`→`は右に結合する．

### 課題

確かめるべきことを`TESTLIST.md`に書き出す．

- 関数と関数適用の評価，簡約，型付けの具体例を考える．関数そのものの値は何か．
- 関数を引数として受け取る関数(高階関数)の例を入れる．
- 型エラーの具体例を，引数の型が合わない場合と，関数でない式を適用する場合で考える．
- 関数適用と関数型の表示で，かっこが要る場合と要らない場合を考える．
- 既存の定理のうち，関数の場合を足す必要があるものを挙げる．

## 6-5 テストファーストの実装

### 構文と構文解析器

1. `Ty`，`Term`，`Value`に構成子を足し，構文解析器を置き換える．
2. `lake build`で，場合が足りない定義と証明の一覧を確かめる．

### 意味論と評価器

テストリストの順に具体例を足し，`subst`，`Eval`，`IsValue`，`Step`，`step`，`Term.toValue?`，`Value.toTerm`に場合を足す．
既存の定理の証明にも，関数と関数適用の場合を足す．

次のヒントを参考にする．

- 小ステップ意味論の関数適用の規則は3つある．関数を簡約する規則，関数が値になってから引数を簡約する規則，両方が値になってからβ簡約する規則である．
- `step`の関数適用の場合は，`match t₁.toValue?, t₂.toValue? with`で場合を分ける．関数でない値に値を適用した場合は`none`(行き詰まり)にする．
- `step_sound`の関数適用の場合では，`split at h`の後に，`next`で`t₁.toValue? = some (.lam x A b)`などの仮定に名前を付ける．

### 型付け

`HasType`と`typeOf`に関数と関数適用の場合を足し，`TypingTest`の定理を広げる．

次のヒントを参考にする．

- 弱化と置換補題の`fun`の場合は，`let`の本体の場合と同じ形になる．
- 進行の関数適用の場合には，関数型を持つ値は関数であるという標準形補題が要る．
- 保存のβ簡約の場合は，関数の型付けを`cases`で分解して本体の型付けを取り出し，置換補題を使う．

### 表示と`run`

`Term.pretty`，`Value.pretty`，`Ty.pretty`，型エラーの表示を直し，統合テストを足す．

最後に，使用例のとおりに表示されることを確かめる．

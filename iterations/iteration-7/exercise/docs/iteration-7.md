# Iteration 7 再帰

このIterationでは，Miniに再帰関数`fix f (x : A) : B => t`を足す．
本体`t`の中で，`f`を自分自身として呼べる．
評価が終わらない式を書けるようになるが，型安全性は保たれることを証明する．

## 7-1 準備

このパッケージは，Iteration 6の解答と同じ状態から始まる．

``` sh
cd iterations/iteration-7/exercise
lake build
lake test
```

Iteration 6までのテストがすべて通ることを確かめる．
`handout/Parser.lean`は，再帰関数に対応した構文解析器である．

- [導出を組み立てる・主張を一般化する](../../../docs/lean/iteration-7.md)
- [一般再帰と停止しない評価](../../../docs/semantics/iteration-7.md)

   (\mathsf{fix}\ f\ (n : \mathsf{Nat}) : \mathsf{Nat} \Rightarrow \mathsf{if}\ \mathsf{iszero}\ n\ \mathsf{then}\ 0\ \mathsf{else}\ f\ (n - 1))\ 1

3. 上の再帰関数の型を，型付け規則で導出する．本体の型を求めるときの文脈はどうなるか．

## 7-3 テストリスト

### 要件

- 再帰関数`fix f (x : A) : B => t`を足す．`t`の中で`f`を自分自身として呼べる．
- 燃料を使い切ったら，評価が終わらなかったことを表示する．

### 使用例

```text
$ lake exe mini eval "(fix fact (n : Nat) : Nat => if iszero n then 1 else n * fact (n - 1)) 5"
120
$ lake exe mini eval --fuel 1000 "(fix loop (n : Nat) : Nat => loop n) 0"
燃料切れ：1000ステップで評価が終わらなかった
```

### 作るもの

| モジュール | 定義 | 内容 |
| --- | --- | --- |
| `Mini.Syntax` | `Term`の構成子`fix (f x : String) (A B : Ty) (t : Term)` | 再帰関数 |
| | `Value`の構成子`fix (f x : String) (A B : Ty) (t : Term)` | 再帰関数の値 |
| `Mini.SmallStep` | `IsValue`の構成子`fix` | 再帰関数は値を表す式である |
| そのほか | 各モジュールに再帰関数の場合を足す | |

本体の型が結果の型の注釈と合わないときの型エラーは，`再帰関数の本体の型が合わない(期待：Bool，実際：Nat)`の形にする．
再帰関数は`fix f (x : Nat) : Nat => t`の形で表示する．
再帰関数の値は，その再帰関数を表す式として表示する．

### 課題

確かめるべきことを`TESTLIST.md`に書き出す．

- 再帰関数の評価，簡約，型付けの具体例を考える．再帰関数そのものの値は何か．
- 評価が終わらない式`loop 0`について，大ステップ意味論，小ステップ意味論，評価器，型付けのそれぞれで何が言えるかを考える．
- 型エラーの具体例を考える．
- 既存の定理のうち，再帰関数の場合を足す必要があるものを挙げる．主張が変わるものはあるか．

## 7-5 テストファーストの実装

### 構文と構文解析器

1. `Term`と`Value`に構成子を足し，構文解析器を置き換える．
2. `lake build`で，場合が足りない定義と証明の一覧を確かめる．

### 意味論と評価器

テストリストの順に具体例を足し，`subst`，`Eval`，`IsValue`，`Step`，`step`，`Term.toValue?`，`Value.toTerm`に場合を足す．
既存の定理の証明にも，再帰関数の場合を足す．

次のヒントを参考にする．

- 置換では，`f`と`x`のどちらかが置き換える変数と同じなら，本体を置き換えない．
- 再帰関数の適用の規則は，本体の`x`を引数の値で置き換えてから，`f`を再帰関数自身で置き換える．大ステップ意味論では`appFix`，小ステップ意味論では`betaFix`という名前にする．
- `loop 0`に値がないことは，`suffices`で「`t ⇓ v`ならば`t`は`loop 0`でない」に一般化してから，導出についての帰納法で示す．
- `loop 0`がどれだけ燃料を与えても燃料切れになることは，燃料についての帰納法で示す．

### 型付け

`HasType`と`typeOf`に再帰関数の場合を足し，`TypingTest`の定理を広げる．

次のヒントを参考にする．

- 型付け規則では，本体の文脈に`x`と`f`の両方の型を加える．`x`を先頭に置く．
- 関数型の標準形補題は，「関数型を持つ値は関数か再帰関数である」に変わる．
- 置換補題の再帰関数の場合は，`by_cases`で`f`と`x`のどちらかが置き換える変数と同じかどうかを分ける．同じ場合は`rcases`で等式を取り出してから，文脈の包含を示す．
- 保存の`betaFix`の場合は，置換補題を2回使う．

### 表示と`run`

`Term.pretty`と型エラーの表示を直し，統合テストを足す．

最後に，使用例のとおりに表示されることを確かめる．

## 7-7 発展課題

Iteration 6の発展課題で定義した名前呼びの簡約を，テストファイルの中でもう一度定義する．
値呼びでは評価が終わらないが，名前呼びでは値に着く式の例を見つけて，そのことを証明する．
評価が終わらないことは，その式から簡約して着く式がその式自身だけであることで示す．
その式に型は付くか．

これも，テストリスト，設計書，実装の順に進める．

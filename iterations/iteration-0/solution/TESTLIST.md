# テストリスト

## 単体テスト

### `Mini.Eval`(`MiniTest/Unit/EvalTest.lean`)

- [x] 数`3`の値は`3`である．
- [x] `1 + 2`の値は`3`である．
- [x] `5 - 2`の値は`3`である．
- [x] `2 - 5`の値は`0`である(引く数のほうが大きい)．
- [x] `2 * 3`の値は`6`である．
- [x] `1 + 2 * 3`を表す式の値は`7`である(演算子を組み合わせた式)．
- [x] `eval_add_comm`：$t_1 + t_2$と$t_2 + t_1$は等価である．
- [x] `eval_add_assoc`：$(t_1 + t_2) + t_3$と$t_1 + (t_2 + t_3)$は等価である．
- [x] `eval_mul_comm`：$t_1 * t_2$と$t_2 * t_1$は等価である．
- [x] `eval_mul_assoc`：$(t_1 * t_2) * t_3$と$t_1 * (t_2 * t_3)$は等価である．
- [x] `eval_mul_one`：$t * 1$と$t$は等価である．
- [x] `eval_sub_not_assoc`：$(t_1 - t_2) - t_3$と$t_1 - (t_2 - t_3)$は，等価とは限らない．

## 統合テスト

### `Mini.Run`(`MiniTest/Integration/RunTest.lean`)

- [x] `run "1 + 2 * 3"`は`"7"`である(`*`が`+`より強く結合する)．
- [x] `run "(1 + 2) * 3"`は`"9"`である(かっこ)．
- [x] `run "10 - 2 - 3"`は`"5"`である(`-`を左から結合する)．
- [x] `run "2 - 5"`は`"0"`である．
- [x] `run "1 +"`は構文エラーを表示する．
- [x] `run_of_parse`：構文解析に成功した文字列を`run`すると，その式の値が表示される．
